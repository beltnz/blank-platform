# Blank Production Application Platform — 0.02.0

This is the condensed canonical Blank framework.

## Canonical documents

`00` intent; `01` architecture/taxonomy; `02` AI constitution; `03` reusable capability/service contracts; `04` security; `05` Definition of Done + delivery obligations; `06` technology decisions; `06A` implementation recipe; `07` dev/test; `08` workflow/model/cost/Superpowers cooperation.

## Key rules

- Blank works with or without Superpowers.
- Blank authority wins conflicts.
- Mature contracts/tools are immutable by default.
- Search toolbox before creating reusable code.
- If the toolbox genuinely lacks the needed reusable primitive, stop and ask the user; the user may prefer an existing GitHub/package solution.
- Capabilities/services/policies/delivery obligations are distinct.
- Cost optimization must preserve security and release confidence.
