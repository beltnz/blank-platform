# Changelog

All notable changes to Blank Platform will be documented in this file.

## [0.02.0] - 2026-09-07

### Added

- Consolidated Blank Platform foundational document set.
- Technology Configurator v0.9.0.
- Foundation capability, platform service, cross-cutting policy, and delivery obligation taxonomy.
- Canonical rules for persistence/data access, validation, secrets management, tenancy, authorization, audit, configuration, notifications, background jobs, feature flags, observability, migrations, security, and operational tooling.
- Toolbox Gap rule requiring reuse and human approval before new reusable infrastructure is created.
- AI engineering operating model with cost, context, risk, and verification controls.
- Optional Superpowers integration under Blank authority rules.
- Release integrity manifest covering the distributable repository.

### Changed

- Reduced framework document volume substantially while retaining canonical guardrails and architectural intent.
- Reorganised repository into canonical framework, supporting documentation, metadata, and tooling.
- Reworked public README for project introduction and adoption.

### Security

- Strengthened explicit tenancy, authorization, validation, secrets, audit, data lifecycle, migration, backup/recovery, and supply-chain expectations.
